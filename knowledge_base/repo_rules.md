\# AutoPR Repository Rules



\## General Rules



\- Never hardcode API keys or secrets.

\- API keys must be loaded from environment variables.

\- Do not modify unrelated files.

\- Preserve existing project architecture.

\- Follow existing naming conventions.

\- Prefer small, focused changes.

\- Do not remove existing functionality unless explicitly required.



\## Git Rules



\- Create changes on the assigned feature branch.

\- Commit changes with a meaningful commit message.

\- Do not commit secrets or .env files.

\- Pull requests must contain a clear description of the implemented change.



\## Code Changes



\- Inspect existing code before modifying it.

\- Reuse existing functions and utilities when appropriate.

\- Avoid unnecessary dependencies.
